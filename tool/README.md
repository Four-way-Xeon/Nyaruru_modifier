# 咸鱼喵喵全能助手 · 使用说明

一个在浏览器里操作的本地辅助工具，支持剧情全文搜索、传送、摆拍、悬停、角色与背包管理、战斗倍率、收集百科和世界地图，方便回看剧情、截图和探索。

发布版更新：2026-10-24。

需要 Windows、已安装的《咸鱼喵喵》、[Node.js 22 或更新版本](https://nodejs.org/)，以及 [NW.js SDK 0.64.1（Windows x64）](https://dl.nwjs.io/v0.64.1/nwjs-sdk-v0.64.1-win-x64.zip)。发布包不含游戏本体、存档、完整剧本和上述运行环境；无需 npm install。

1. 将下载解压后、包含 `tool`、`out`、`unpacked` 的整个工具文件夹放进游戏安装目录，与游戏的 `package.json` 同级。外层文件夹名称不限，保留下载后的名字即可，无需另建 `aitemp` 文件夹。可从 Steam 的“管理 → 浏览本地文件”找到游戏目录。
2. 解压 NW.js SDK，把 `nwjs-sdk-v0.64.1-win-x64` 文件夹放进上述工具文件夹。保留内部目录结构，别多套一层文件夹：

   ```text
   Nyaruru（游戏目录）
   ├─package.json
   └─Nyaruru_modifier（名字不限）
       ├─README.md
       ├─.gitignore
       ├─nwjs-sdk-v0.64.1-win-x64  ← 另行下载并解压
       │  └─nw.exe
       ├─out
       │  └─triggers.csv
       ├─tool
       │  ├─启动.bat
       │  ├─停止面板.bat
       │  ├─lib
       │  └─web
       └─unpacked
           └─data
               ├─System.json
               └─MapInfos.json
   ```
   （仅列出主要文件；NW.js SDK 文件夹需完整保留。）

3. 先在原游戏中正常保存一次并退出。双击 `tool/启动.bat`，首次选择 **1：只启动面板**，在“存档与沙盒”页创建游戏副本。副本需要额外磁盘空间，默认放在游戏所在盘的 `Nyaruru_shots` 文件夹。
4. 副本创建完成后，再次双击 `启动.bat`，工具会备份存档并启动副本游戏。在游戏里正常读档进入地图，确认面板顶部连接的是沙盒。
5. 在面板搜索台词或故事编号，按需要选择“前往”“运行过场”或“只播台词”；摆拍后可点“撤销场景还原”。全文台词在连接游戏后自动读取，断开连接后清空。

面板默认地址为 `http://127.0.0.1:8787`。用完双击 `tool/停止面板.bat`，游戏窗口另行关闭。升级前先退出旧面板和游戏。

建议始终在沙盒里使用：剧情操作可能改变进度，自动存档和手动保存照常生效。“全部还原”会解除临时效果和锁定，但不会回退已经改过的数值、背包或剧情进度；摆拍状态也不保证能通过读档完整恢复。详细说明见包内 `tool/使用须知.md`。

## 独立目录安装与配置

默认按上面的步骤放进游戏目录，无需手工配置。希望工具放在其他目录时，将 tool/config.example.json 复制为 tool/config.json，再把 gameDir 和 sandboxDir 改成实际路径。示例中的 C:/Games/Nyaruru 只是占位路径，不能直接用于启动。

原版和副本路径必须完全分开，不能互相包含；两个端口也不能相同。JSON 路径可以使用正斜杠（例如 C:/Games/Nyaruru）；修改游戏目录或面板端口后重启工具。不要公开自己的 config.json、存档、日志或 backups。

## 悬停与取景

「悬停」保持高度，空中每次点跳都能继续上升，不受二段跳次数限制；上升仍会减速到顶。按住游戏的「下」键下降，松开停住。原有技能触发条件不变，下冲等技能的主动位移保留，技能结束后恢复悬停。

悬停状态独立于原版技能的临时重力标记，技能或受击结束时不会把它关闭；面板刷新读取实际辅助开关，不把技能自带的短暂浮空显示成悬停。

普通悬停保留原版碰撞，下降遇到实心地面会停住；穿墙开启后才忽略四个方向的碰撞。原作允许下穿的平台仍遵循原版规则。穿墙自动启用悬停；关闭穿墙会检查地形重叠，已经卡在地里时先开穿墙飞到空处，再关闭。

悬停支持通过原版地图出口换图，并保留悬停和穿墙设置；只有没有可用出口的边界会挡住。穿墙也不会凭空建立地图连接。读档仍会解除旧辅助。点击「落地」会检查脚下安全性，再恢复重力和碰撞。

方向按钮从角色真实位置按 1/4/16 像素微调，支持长按。「全部还原」解除物理辅助、摆拍、数值锁定和战斗倍率，不回退已经修改的背包、数值或剧情进度。

## 角色、背包与战斗

背包列出全部 48 项，包括 26 种配饰、食物、咸鱼武器、鱼眼宝石、材料和铃铛。图标由当前游戏的图标组件在内存中生成，不导出素材文件；效果文字为 16px。

支持单项添加、删除、装备、卸下，以及对筛选结果批量获得或清除。批量操作先验证全部参数，执行失败会回退；至少保留一件武器。铃铛决定配饰容量，减少容量会卸下多出的配饰。默认保留地图铃铛；勾选允许减少后可清零，对应收集点按地图编号从后往前重置。其他背包操作不会改变地图收集记录。

金币、HP、SP、ZP 支持设值和独立锁定。伤害与受击倍率范围为 0～1000，1 为正常；一击秒杀在玩家或莉莉娅的有效攻击命中敌人时生效，不突破剧情无敌，不把治疗变成伤害。受击 0 倍仍可能受到击退。

数值锁定和战斗设置只在本次游戏中生效，读档会清理。面板失联两分钟也会解除这些辅助。

## 收集百科与剧情

百科显示 49 种物品、426 条地图来源、24 处商店入口，覆盖当前版本全部 411 个地图收集点（含 32 个猫币堆）。按区域和状态筛选，可前往来源分块附近。当前持有与地图收集分别显示，吃掉食物不等于没拿过。

「前往分块边缘」根据事件所属的原版小地图格子定位，优先找分块边缘附近、角色身体不碰墙且脚下没有伤害地形的落脚空处；没有地面时可使用经过检查的空中位置。这个分块被堵住时继续找邻近分块，再找同一张地图的其他空处，并在提示中说明改了位置。到达后保持悬停、恢复碰撞，不自动开穿墙，也不直接传到物品旁。跨图载入后再次检查；只有整图都找不到可容纳角色的落点时才失败，必要时尝试返回原地图与原位置。

事件坐标可能是发奖控制点，不一定就是道具贴图的位置。工具不主动更改获取条件或收集开关，到达分块后自行前往获取。地点按钮使用固定编号，刷新百科不会再因对象引用变化而失效。

商店为候选入口，库存受任务进度影响。普通敌人掉落与脚本动态奖励尚未纳入来源索引；无法判断的分支奖励标为未知。拾取、读档或修改背包后刷新百科。

对话剧情保留前往、只播台词、运行过场和临时摆拍。分支剧情可能跳过先前摆位；前往只处理普通开关。发布版连接游戏后自动从运行时读取全文台词，全部只保存在内存，断线清空、重连补齐；未连接时仍能搜索结构索引。读取失败可点「重新读取台词」。

## 世界地图

面板「地图」页按游戏原版房间与通道布局绘制示意图，支持选择大区域（例如喵喵小镇、封印结界）和地图页。当前读取 16 个区域、12 个地图页、996 个分块；未探索和隐藏分块也会显示，但查看本页不会解锁游戏里的探索记录。

地图标出 426 条已知来源，覆盖 411/411 个官方收集点。未收集物显示正常图标，已收集变灰并标 ✓，无法判定的标 ?；可以筛选类型或只看未收集。鼠标悬停查看名称、状态和效果，点击方格或图标在右侧查看该分块全部物品、条件和来源。额外脚本点与未知分支沿用百科的标记规则。

金币使用带双层币边和猫爪纹样的专用图标，币面扩大至接近图标框大小，放大后仍清晰；地图与右侧详情保持一致。

拖动平移、滚轮或加减按钮缩放；「适应地图」显示当前选择的完整布局，「定位当前」切回角色所在区域。放大后更容易看清图标，自动刷新会保留缩放、平移与选中项。

点击分块只选中；右侧「传送到此分块」才移动角色，空分块也支持。落点使用上面的分块边缘与备用位置逻辑：目标受阻时继续找邻近分块、同图其他空处，到达后悬停并恢复碰撞。先关闭游戏菜单回到地图再传送；地图、存档或连接变化后须等待本页刷新。传送不替你领取物品或满足剧情条件。

发布版不提供快照与 TAS（逐帧/输入录制）功能；常规存档备份与还原保留。
