坐标传送

输入目标格子的横纵坐标。坐标超出地图范围会被自动夹到边界。

传送默认进入「悬浮」状态（暂停重力 + 穿墙）。
这是为了避开游戏的坠落复位机制 —— 直接落到坑洞地形上，游戏会判定你掉下去了， 播掉落音效并把你弹回"上次站立的位置"，如果这个记录还是上一张地图的，人就会直接消失。
想站到地上走动时，点下面的「落地」（会先探测脚下安不安全）。
悬停时每次点跳都能继续上升；按住游戏「下」键下降，松开停住，遇到实心地面会停下。下冲等技能保留原有位移。开「穿墙」后四向均可穿过障碍；已卡进地里时先开穿墙飞到空处再关闭。支持原版出口换图并保留设置，无出口的边界仍会阻挡。方向微调点按小步移动，按住连续移动。

场景还原（摆拍）

找出本图本该可见却没出现的角色，强行让它们出现。 用于「对话框在说话、画面里却没人」的情况。

⚠️ 这是摆拍，不是把游戏改回当时的样子。
· 被游戏标记为「已抹除」的事件强行拉出来，它不会执行任何指令， 只是一个站着的立绘；站位也不一定和原作一致。
· 摆拍会固定角色，自动和手动存档照常。不推荐摆拍时保存：读档后状态可能无法完整恢复。完成后可点「撤销场景还原」恢复原来的事件状态。 切图、读档或面板失联两分钟也会撤销摆拍。
· 如果这条对话有「运行过场」可用，优先用那个——那个是真的在重现演出。

对话剧情

连接后自动读取台词，支持全文搜索。
从游戏数据里解析出的 — 条剧情触发点。

三种复现方式，优先试「运行过场」
· 运行过场 —— 执行含这段对话的整个事件页。 NPC 站位、演出、对白全按原样走，画面最接近原作。通关存档也能用。
   注意：一整段过场会从头播，可能包含好几段对话，一路截图即可。
· 只播台词 —— 只调那一段对白，跳过节目前的演出。快，但 场景里的 NPC 可能不在场（那些角色是靠前面的指令摆出来的）。
· 前往 —— 打开所需开关 + 传送，你自己走过去。存档没通关时场景最自然。

⚠️ 用之前先读这段

  • 本工具会改游戏运行时状态（坐标、开关、物理），不改游戏程序和素材；保存、还原会写入明确选定的存档目录。
  • 作弊状态下游戏可能自动存盘，落到 file0（自动存档槽）。
  • 本游戏启用了 Steam 云存档。直接在原版游戏上折腾，被污染的存档可能被同步上去且追不回来。
  • 所以推荐用沙盒：把游戏整体拷一份，在副本里折腾。副本不在 Steam 库里，云同步够不着。

关于这个工具

粉丝向的截图辅助工具，用于个人复现「错过就没了」的剧情并截图。
不包含、不打包任何游戏素材；不提供成就解锁功能；不修改游戏任何文件。
按作者 readme 的要求，请勿用本工具提取或传播游戏素材。

端口与路径

改完点保存即可生效，配置文件写在 tool/config.json。

怎么启动这个工具

  1. 双击 tool\启动.bat
  2. 它会自动：检查 SDK 版 NW.js → 备份存档 → 启动游戏 → 启动本服务 → 打开浏览器
  3. 在游戏里正常读档进入地图（工具不能替你读档，见开发文档第 6 节）
只想启动某一部分？
· 只起控制面板（游戏已经在跑）：在这个目录执行 node server.js
· 只启动游戏：nw.exe "沙盒目录" --remote-debugging-port=9223
· 改了控制面板端口后，要关掉旧的服务窗口再重新 node server.js
