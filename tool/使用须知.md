# 使用须知（发布版）

更新：2026-10-24。完整功能说明见 [README](README.md)。

## 先确认实例

看面板「当前连接」，建议确认为已创建的沙盒副本。端口可达不等于已读档；标题界面请从游戏正常菜单进入。移动/剧情需回地图，背包、百科和战斗支持菜单画面。

不要自行调用裸 DataManager.loadGame：本游戏读档还要重建物理网格。请通过游戏菜单正常读档。

## 常见操作

| 提示或现象 | 处理 |
|---|---|
| 端口上的游戏与目标不符 | 关闭占用实例或改端口，不会自动放行 |
| 地图、存档或连接已变化 | 刷新并重读旧列表 |
| 百科“前往分块边缘” | 优先目标分块边缘，堵住就改到邻近分块/同图其他空处，保持悬停并恢复碰撞，再自行前往获取 |
| 地图怎么传送 | 点击方格或图标选中，再点右侧「传送到此分块」；游戏菜单中可看图，需回地图后传送 |
| 地图太小或图标看不清 | 选择大区域后点「适应地图」，用滚轮/加号放大、拖动查看 |
| 地图灰色图标和问号 | 灰色 ✓ 为已收集，? 为条件无法判定；「只看未收集」不包括未知点 |
| 图标尚未加载 | 等待片刻，或点刷新数值与背包；不影响数量操作 |
| 关闭穿墙被拒绝 | 先微调到空处；开着悬停不代表已离开墙体 |
| 脚下没有安全地面 | 继续悬停，移动到安全处再落地 |
| 空中跳跃/下降 | 悬停中可连续点跳，按住游戏下键下降；技能移动保留 |
| 悬停与穿墙的区别 | 悬停仍受实心地形阻挡；开穿墙后四向均可穿过 |
| 已经卡进地里 | 先开穿墙，跳到空处再关穿墙；脚下安全后可落地 |
| 悬停换地图 | 通过原版出口换图，保留悬停和穿墙；无出口的边界仍会阻挡 |
| 配饰栏位不足 | 增加铃铛或卸下其他配饰 |
| 无法减少地图铃铛 | 勾选对应选项；此举会重置部分地图收集点 |
| 秒杀没有生效 | 需有效命中敌人；不会突破剧情无敌或无限生命对象 |

## 保存与恢复的边界

普通手动和自动存档照常，数值和背包修改可能随游戏保存。全部还原只解除辅助，不回退物品、数值及剧情变化。

发布版不提供快照、逐帧或输入录制（TAS）。常规游戏存档备份与还原继续可用。

## 数据来源与收集状态

百科里的「背包未拥有」和「地图未收集」不是同一回事。食物吃掉或配饰删除后，原来的拾取记录仍在。商店只列候选入口，实际库存由进度决定；未知奖励不会被判成未收集。

面板「地图」显示原版分块示意布局，包含未探索和隐藏区域；查看不会修改游戏探索记录。它与百科共用来源和状态，当前覆盖全部 411 个官方收集点，但未索引的动态掉落也不会凭空出现在图上。分块传送复用百科备用落点规则，目标受阻时可能抵达同图的邻近分块或其他空处，请留意到达提示。

发布版从当前游戏运行时读取全文台词，仅保存在内存中。自动读取最多尝试四次、间隔至少三秒；失败后可手动重新读取。断线、换实例和重连会清除旧内容；未连接时仍可搜索地图、坐标、事件和条件。百科、世界地图与物品图标同样从运行时读取，无需提供完整提取资料。

## 剧情、摆拍与备份

运行过场会执行整个事件页，可能改变开关和剧情；只播台词不等于完整还原演出。#305 的整页过场可能先播放 #298/#299，直接回看请用只播台词。临时摆拍不保证跨读档恢复；切图、正常读档或面板失联两分钟会撤销，普通存档照常生效。升级前关闭旧面板和游戏，再启动新版本并刷新页面。

还原备份前先关闭游戏。工具校验存档文件与来源，保留还原前的 save 目录和额外安全备份；目标自己的 Steam 云配置保留。备份不存在的槽位不会混入恢复结果。任何恢复操作都应明确选择原版或沙盒目标。

详细安装与默认端口见 README；独立目录可使用 config.example.json，但必须先修改示例路径。
