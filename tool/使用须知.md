# 使用须知（发布版，2026-10-03 修订）

## 确认当前操作哪份游戏

看顶部“当前连接”和存档页“实际保存目录”。身份从游戏的 Node 入口及 StorageManager 存档路径读取，不依赖网页 URL。实机网页 URL 是 chrome-extension 地址。

调试端口可达不等于已连接，更不等于已进入地图。标题画面请正常读档；不要从外部直接调用 DataManager.loadGame 绕过游戏的 completeLoad 流程。

## 常见提示

| 提示或现象 | 处理 |
|---|---|
| 调试端口和面板端口相同 | 设置两个不同的端口，再启动 |
| 端口上的游戏与目标不符／无法识别 | 关闭占用该端口的游戏，或为各实例配置不同端口；不会自动放行 |
| 旧服务或旧配置占用面板端口 | 停止旧面板后再启动；本次升级前的旧服务需关闭原来的命令行窗口 |
| 副本缺失／复制未完成 | 不启动残缺副本；选择新的空目录重建。不会覆盖已有目录 |
| 地图、存档或连接已变化 | 刷新状态并重新读取本图事件／扫描角色，旧列表不能用于新地图 |
| 莉莉娅脚下不安全 | 她保持悬浮；移动到安全地面再点“落地” |
| 跨地图超时 | 工具会取消尚未完成的传送请求；确认游戏是否被菜单或演出占用，再重试 |
| 备份失败 | 不会继续启动需要备份的游戏或覆盖槽位。检查目录、磁盘空间及是否仍在写档 |
| 当前有摆拍角色，提示不推荐保存 | 读档后摆拍状态可能无法完整恢复；可自行决定继续保存，不要求先撤销 |

悬浮时按跳跃仍可能一直向上运动；关重力没有取消跳跃输入。落地会检查地形，“全部还原”会直接恢复正常物理状态，使用时应处于安全位置。

## 搜索和剧情

发布版从游戏运行时读取全文台词，全部在内存中使用，不写剧本或缓存文件。先开面板再开游戏也会自动读取；故事表未就绪时最多尝试四次、间隔至少三秒，仍失败会显示原因，可手动重新读取。断线、换实例或重连都会使旧台词失效，重连成功后自动补齐。

搜索覆盖整段台词和说话人，并显示命中句；未连接时仍可搜索地图、坐标、事件和条件。

“运行过场”包含剧情指令，可能改变游戏开关和进度。分支剧情可能跳过先前的演出；前往只自动设置普通开关，不承诺还原完整历史进度。没有任何一页提供角色形象的事件，也不能凭空生成合适 NPC。

## 场景还原与撤销

恢复的角色是固定的摆拍对象，不再自动执行原事件、移动或参与物理碰撞。清除“已抹除”状态只是临时操作；撤销会恢复修改前的字段、原有抹除状态及方法。

“被抹除”不证明这个人应该出现在当前剧情。选择哪些角色和站位仍需核对画面；不要把全部恢复后的画面当成原作的准确复现。

摆拍期间自动和手动存档照常，工具不拦截游戏自身的保存。顶部提示不推荐摆拍时保存；面板保存的原有确认框会说明风险，仍可确定继续。完成后可撤销；切图或正常读档自动撤销。面板关闭或失联超过两分钟也会撤销，恢复事件原有行为。

这次没有实现“保存并读回完整摆拍布局”。临时函数、UI 显示状态、剧情解释器不承诺跨存档复现。

## 备份与还原

- 新备份记录来源，使用唯一目录并校验每个 .rmmzsave 文件。未完成或损坏备份不列为可恢复项。
- 旧时间戳备份仍可读取，但显示来源未知。还原时必须明确选目标，不能凭备份名称猜。
- 还原前先退出游戏和 NW.js 游戏窗口，防止运行中的游戏把旧状态写回。
- 还原得到所选备份中的完整存档集合；备份没有的槽位不会继续留在当前 save 目录。
- 当前存档会先备份；原 save 目录保留为游戏目录下的 `.save-before-restore-…`，不会直接删除。
- steam_autocloud.vdf 等非存档文件保留目标目录自己的版本，不从另一份游戏的备份覆盖。

## 已知画面限制

先前记录的“切换剧情分支时角色短暂抽动”，没有足够实机证据保证所有地图均已解决；本轮不把它标成已修。相同立绘的多个事件、剧情自身的移动与刷新仍可能影响演出效果。

并非全部剧情均已验收。遇到问题请记录故事编号、地图、事件页、存档进度和使用的按钮。

## 角色与背包、锁定

“角色与背包”页可设置并分别锁定金币、HP、SP、ZP，以及搜索、添加、移除背包物品。作用于当前操作角色，包含切换后的莉莉娅形态，不修改独立跟随的莉莉娅。金币范围 0～99999，其余不能超过当前最大值；不会改变上限。已倒下时请先在游戏里复活或读档。

消耗品默认遵循携带上限，可勾选超上限（最多 99999）。移除装备会同步卸下，移除当前武器会换到另一件已有武器，至少保留一件。铃铛容量、任务及收集进度不在修改范围内。

锁定立即阻止该数值的消耗和增加。读档、新游戏、面板失联超过两分钟或点“全部还原”会解除锁定；已修改的数值和背包不会回退，正常保存会把当前数值和物品写进存档。

本轮同时更新了摆拍人物贴地、原图待机动画和面向主角。仅对原页要求贴地的人物小范围探地，飞行角色和固定摆件不强制落地；撤销恢复原始位置和朝向。首次升级这批摆拍修复，需要重启面板和游戏后刷新网页。
